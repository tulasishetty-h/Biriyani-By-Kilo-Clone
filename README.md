# 🍲 Biryani By Kilo - Frontend Clone

A responsive, pixel-crafted web landing page clone of **Biryani By Kilo (BBK)** built with pure **HTML5** and **CSS3**.

---

## 📸 Preview

The project replicates the design and user interface of India's popular biryani delivery and dining platform, featuring promotional banners, categorized menus, discount deals, and interactive UI components.

---

## ✨ Features

- 🧭 **Sticky Navigation Header**:
  - Brand logo and interactive location picker
  - Quick action links: *Search, Outlets, Menu, Bulk Order, Book a Table*
  - Digital wallet quick link and branded Login CTA button
- 🏷️ **Promotional Offers & Discounts**:
  - Horizontal promotional cards showcasing bulk order savings, first-order discounts, and percentage-off coupons
- 🍛 **Food Categories & Filters**:
  - Filter by dietary preferences (*Veg*, *Non-Veg*, *Best Seller*)
  - Category cards for *Hyderabadi, Lucknowi, Kolkata, Sattvik, Combos, and Daily Deals*
- 🏷️ **Special Deal Sections**:
  - **Today's Deals** (Rolls & Starters starting @ ₹249)
  - **Sattvik Specialities** (No-onion, no-garlic pure vegetarian preparations)
  - **Lucknowi (Awadhi) Dum Biryani** (Pack size variants with pricing and discount coupon tags)
  - Veg / Non-Veg diet indicator badges
  - Weekly order popularity metrics and price discount badges
- 📱 **Rich Footer**:
  - Useful links, food blogs, and informational resources
  - Customer care toll-free numbers and contact details
  - Mobile app download links (*Google Play* & *Apple App Store*)
  - Social media integration icons

## 🚀 Getting Started

### Prerequisites

You only need a modern web browser (Google Chrome, Mozilla Firefox, Safari, Microsoft Edge).

### Running Locally

1. **Clone or download** the repository:
   ```bash
   git clone <repository-url>
   cd Biriyani
   ```

2. **Open the project**:
   - Simply double-click `index.html` to open it in your browser, or
   - Use the VS Code [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) extension for auto-reloading during development.
